# 相似形研究室

繁體中文、手機友善的國中數學靜態互動教學網站。

## 學習內容

- 比例與連比、相似與面積、直角三角比、綜合應用四個主題
- 逐步解說與可拖曳的相似形實驗
- 8 張重點翻卡、12 題即時詳解測驗、錯題重練
- 19 題重繪圖形與解題過程

題目涵蓋提供教材中的第 1–17、24–25 題；未提供的題目不予補造。第 25 題部分文字缺漏，已註記依附圖關係整理。本站不包含原始照片或個人資料。

## 執行與部署

純 HTML、CSS、JavaScript，無建置步驟或外部依賴。從此目錄啟動靜態 HTTP 伺服器即可預覽。

GitHub Pages 發布來源為 `main` 分支的根目錄。`.nojekyll` 保留靜態檔案原樣。

## 本地進度

學習與測驗進度僅儲存在使用者自己的瀏覽器 localStorage，不上傳到伺服器。可從頁尾「進度與資料」清除。
